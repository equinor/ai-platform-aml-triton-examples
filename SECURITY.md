# Security

If you discover a security vulnerability in this project, do not create a public GitHub issue containing sensitive details.

## Reporting a vulnerability

- For non-critical issues, contact the [AI-Platform administrators in the equinor-ai-platform-support Slack channel](https://equinor.enterprise.slack.com/archives/CNRUA060Y).
- For critical or time-sensitive issues, follow Equinor's [Responsible Disclosure Policy](https://www.equinor.com/about-us/csirt).

Please include the affected code, steps to reproduce, potential impact, and any proof of concept when available.
